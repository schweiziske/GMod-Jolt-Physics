# 额外玩法

[项目首页](../README.zh-CN.md)

`jolt` addon 在 Sandbox 中加入五项基于 Jolt 的玩法。使用前需要按[安装指南](INSTALL.zh-CN.md)装好三个可选模块和 addon。

| 玩法 | 入口（Q 菜单） | 简介 |
| --- | --- | --- |
| [软体](#软体) | 工具 → Jolt → 软体工坊 | 可拖动、可固定顶点的布料和充气软球 |
| [黑洞](#黑洞) | 工具 → Jolt → 黑洞；武器 → Jolt → Jolt 黑洞手雷 | 先把周围物体吸过来，再一口气弹开 |
| [重力场](#重力场) | 武器 → Jolt → Jolt 重力控制器 | 修改整个世界、单个物体或一片区域的重力 |
| [齿轮与齿条](#齿轮与齿条) | 工具 → Jolt → 齿轮 / 齿条 | 按传动比联动两个物体，或把转动变成平移 |
| [轨道](#轨道) | 工具 → Jolt → 路径轨道 · PathConstraint | 让物体沿三维曲线运动 |

界面语言跟随游戏语言（`gmod_language`），支持简体中文和英文，其他语言显示英文。重力场、黑洞和软体的默认参数在 Q 菜单右侧「选项」→ Jolt 中调整。

H 键只在手持支持它的工具或武器时生效；打开菜单、聊天或输入框时会被忽略。

## 软体

在「创建软体」模式下选择布料或软球，调整尺寸、质量、柔软度和网格精细度，然后：

| 操作 | 效果 |
| --- | --- |
| 左键 | 在瞄准的表面放置软体 |
| Z | 撤销放置 |

切换到「编辑顶点」模式后：

| 操作 | 效果 |
| --- | --- |
| 按住左键 | 拖动顶点，松开后恢复它原来的固定状态 |
| 右键 | 固定或松开所选顶点（固定点锚定在世界中） |
| R | 结束拖动 |

普通物理枪抓不到软体，请用软体工坊编辑。详见[软体指南](../gmsv_joltsoftbody/README.zh-CN.md)。

## 黑洞

黑洞会先吸引范围内的物体，持续一段时间后瞬间把它们弹开，然后消失。它只作用于可移动的物理物体，不影响玩家移动。

| 入口 | 操作 |
| --- | --- |
| 工具 → Jolt → 黑洞 | 左键在瞄准的表面放置；右键移除自己最近放置的黑洞 |
| 武器 → Jolt → Jolt 黑洞手雷 | 左键投掷；R 设置半径和持续时间 |

参数在「选项」→ Jolt →「黑洞」中设置：

| ConVar | 默认值 | 范围 | 含义 |
| --- | --- | --- | --- |
| `jolt_blackhole_radius` | 450 | 64–32767（非管理员最多 1024） | 作用半径 |
| `jolt_blackhole_pull` | 2200 | 100–10000（非管理员最多 2000） | 吸引加速度 |
| `jolt_blackhole_burst` | 6500 | 100–20000 | 弹开加速度 |
| `jolt_blackhole_duration` | 2.5 | 0.1–300 | 吸引持续时间（秒） |

服务器用 `sbox_maxjolt_blackholes`（默认 3）限制每名玩家同时存在的黑洞数量。

## 重力场

| 操作 | 效果 |
| --- | --- |
| R | 切换模式：世界重力、物体重力、区域重力场 |
| 按住 E 移动鼠标 | 调整重力方向箭头，松开 E 保存 |
| 左键 | 沿保存的方向施加重力（物体模式作用于准星指向的物体，区域模式在准星处生成重力场） |
| 右键 | 恢复原有重力；区域模式下移除自己最近的重力场 |
| H | 区域重力场在球形和盒形之间切换 |
| Z | 撤销 |

非管理员只能使用区域模式。重力场只影响物理物体和载具，不改变玩家移动和 NPC 行为。详见[重力场指南](../gmsv_joltgravity/README.zh-CN.md)。

## 齿轮与齿条

1. 冻结并摆好两个物体，在面板的「组件类型」中选择「双齿轮」或「齿轮齿条」。
2. 依次左键点击两个物体的端面，点中表面的法线决定转轴或齿条的滑动方向。
3. 解冻物体，机构开始运转。

| 操作 | 效果 |
| --- | --- |
| 右键 | 把面板中的电机设置应用到自己最近创建的机构 |
| R | 取消选择 |
| Z | 撤销机构，保留物体 |

两个模型相互重叠时，请先用 Sandbox 的「无碰撞」工具处理。详见[齿轮与齿条指南](../gmsv_joltconstraints/README.zh-CN.md)。

## 轨道

1. 冻结物体并摆好朝向。
2. 左键放置轨道节点（至少 2 个，闭合轨道至少 3 个）。
3. 右键点击物体完成绑定，再解冻。开放轨道默认往返运动，闭合轨道默认循环。

| 操作 | 效果 |
| --- | --- |
| 左键 | 添加节点 |
| E + 左键 | 选中节点；再按一次把它移到准星处 |
| Shift + 左键 | 在所选节点之后插入节点 |
| R | 删除所选节点，未选中时删除最后一个 |
| H | 开始新轨道 |
| 右键物体 | 绑定物体 |
| E + 右键物体 | 载入该物体的轨道进行编辑 |
| Shift + 右键 | 点物体：以它为移动参考系；点地图：恢复为固定在世界中 |
| Z | 撤销，移除轨道约束但保留物体 |

面板中还可以暂停、反向、调整速度和保存预设。详见[轨道指南](../gmsv_joltconstraints/PATH.zh-CN.md)。
